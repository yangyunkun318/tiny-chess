# tiny-chess

A strong chess engine in under 4 KB of Python (standard library only). 0x88 board, alpha-beta with transposition table, null-move pruning, quiescence search, and iterative deepening with a fixed node budget. Deterministic: no clock, no randomness.

Run it with `MAKEFUN_ENV_URL` set; it speaks the make.fun environment protocol (`/game`, `/move`, `/resign`).

Built with make.fun: https://make.fun/r/zhc1s3ge
